# Prototype

Put your clickable prototype here (built with v0 and Cursor).

## What to add
- Source code (or an export) for the prototype in this folder.
- A live link (e.g. a v0 / Vercel preview) in the main `README.md`.
- 3-5 screenshots in `../assets/` (Home card, goal setup, goal progress, edge-case/error state).

## Screens the PRD expects
1. Home with "Start a goal" card
2. Goal setup (template, amount, date, funding)
3. Goal progress (ring, streak, projected date)
4. Edge cases: low balance skip, failed transfer, goal date passed
5. Completion / withdraw

## Notes
- If you reuse AI-generated code, keep a short note of what you changed yourself.
- Do not include real user data or real bank details.
